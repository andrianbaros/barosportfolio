# Andrian Baros — Personal Portfolio

Professional developer portfolio for **Andrian Baros**, Informatics Engineering student at Universitas Komputer Indonesia (UNIKOM) and Web & Mobile Developer based in Bandung, Indonesia.

Live preview: [https://andrianbaros.vercel.app](https://andrianbaros.vercel.app)

---

## ⚡ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **UI Library**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, PostCSS
- **Animation & Motion**: GSAP (GreenSock) + ScrollTrigger, `prefers-reduced-motion` compliance
- **Icons**: Lucide React
- **SEO & Structured Data**: Metadata API, OpenGraph, Twitter Cards, JSON-LD Schema.org (`Person`, `WebSite`)
- **Accessibility**: WCAG 2.1 AA compliant, `:focus-visible` indicators, keyboard navigation, Skip to Main Content link

## 🛠️ Development & Build

### Prerequisites
- Node.js 20.9+ (or newer)
- npm or pnpm

### Setup
```bash
# Clone the repository
git clone https://github.com/andrianbaros/baros-portfolio.git
cd baros-portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

### Lint & Build
```bash
# Run ESLint validation
npm run lint

# Compile optimized static production build
npm run build

# Start production server
npm run start
```
